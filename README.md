# Hansen J. Tiodianco — Portfolio

A personal portfolio website showcasing my web and software development projects, built as part of my journey toward becoming a full-stack developer.

🔗 **Live Site:** https://elhanxen.github.io

## Sections

- **Home** — Introduction, profile photo, and a short bio
- **Skills** — Technical skills across languages, frameworks, databases, and AI tools
- **Projects** — Featured projects with descriptions, tech stacks, and repository links
- **Education** — Academic background and certifications
- **Contact** — Ways to get in touch

## Technologies Used

- HTML5, CSS3, JavaScript (vanilla)
- Google Fonts (Spectral, Inter)
- Canvas API for background animation
- Responsive design (Flexbox/Grid)
- Deployed via GitHub Pages

## Featured Projects

- **AI-Powered Weather App** — .NET MAUI desktop app integrating the Gemini API for natural-language weather summaries
- **AI Study Assistant** — Full-stack web app (JavaScript, Supabase, Vercel serverless functions) that generates summaries and quizzes from notes or PDFs using the Gemini API
- **Inventory & POS System** — Java Swing desktop application with a MySQL backend for inventory and point-of-sale management

## Setup / Running Locally

This is a static site — no build step required.

1. Clone the repository
2. Open `index.html` in a browser

No environment variables or dependencies needed.
